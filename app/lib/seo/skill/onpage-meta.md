# On-Page Meta Generator — Kimono SEO

Generates product title (H1), meta title, meta description, image alt texts and URL slug
for Shopify product pages. All output must be in correct Romanian language.

---

## Rules — Product Title (H1)

| Rule | Detail |
|------|--------|
| Length | 40-70 characters |
| Content | Descriptive — includes key attributes (material, size, color, use case) |
| No brand | Never include brand name in product title |
| Language | Romanian with correct diacritics (ă â î ș ț) |
| Truncation | NEVER cut a word mid-way — always end at a complete word |
| Numbers | Include dimensions/quantities ONLY if they fit completely (e.g. "18 cm" not "18") |

**Pattern:** `[Produs principal] — [Atribut 1], [Atribut 2], [Dimensiune/Culoare]`

**Examples:**
- `Gnom Beat Decorativ pentru Grădină — Figurină din Rășină, 18 cm, Roșu`
- `Pieptene cu Două Fețe pentru Animale — Oțel Inoxidabil, Mâner Ergonomic`
- `Cutie pentru Baloane Aniversare — 30x30 cm, Transparentă, cu Panglică`

**CRITICAL:** If a number or measurement appears at the end, make sure the unit is included.
Never end with a bare number like "18" — always "18 cm" or "Set 4 buc".

## Rules — Meta Title

| Rule | Detail |
|------|--------|
| Total length | 55-65 characters INCLUDING brand suffix |
| Keyword part | At least 50 chars before brand suffix |
| Brand | Always at end: ` | Brand` or ` ~ Brand` |
| Separator | Use | or ~ — NEVER use dash (-) or em dash in meta title |
| Language | Romanian with correct diacritics |
| No clickbait | No ALL CAPS, no "!!!", no fake urgency |
| Numbers | Include key numbers if they fit (dimensions, quantities) |

**Pattern:** `[Keyword principal] [Atribut cheie] | [Brand]`

**Examples:**
- `Gnom Beat Decorativ Gradina Rasina 18 cm | Kimono SEO` (51 chars total) OK
- `Pieptene Animale Doua Fete Otel Inoxidabil | Kimono SEO` (54 chars total) OK
- `Cutie Baloane Aniversare 30x30 cm Transparenta | Kimono SEO` (58 chars total) IDEAL

**FORBIDDEN in meta title:**
- Dashes or em dashes inside the keyword part
- Total under 55 chars: `Gnom Gradina | Kimono SEO` (only 24 chars) WRONG
- Bare numbers without unit: `Gnom 18 | Kimono SEO` WRONG

## Rules — Meta Description

| Rule | Detail |
|------|--------|
| Length | EXACTLY 150-165 characters — count every character |
| Target | Aim for 155-160 characters for best results |
| Language | 100% Romanian — NEVER mix English words into Romanian text |
| CTA | Must end with: "Comandă acum.", "Comandă azi.", "Adaugă în coș acum." |
| Concrete specs | Include at least 2 specific details from the product (material, dimension, color, quantity) |
| Tone | Warm, persuasive, conversational — NOT robotic or vague |
| No quotes | Google strips double quotes from descriptions |

**Formula:** `[Beneficiu principal] + [Spec concret 1] + [Spec concret 2] + [Diferentiator] + [CTA]`

**GOOD examples (count chars carefully):**
- `Decorează grădina cu acest gnom amuzant din rășină rezistentă, 18 cm, în culoare roșu aprins. Design haios și detaliat, perfect ca decor sau cadou. Comandă acum!` (163 chars) IDEAL
- `Pieptene profesional cu două fețe din oțel inoxidabil pentru câini și pisici. Elimină eficient puful și părul mort, mâner ergonomic albastru. Comandă acum.` (157 chars) IDEAL

**BAD examples:**
- `Gnom decorativ amuzant. Figurină din rășină, 18 cm, roșu.` (57 chars) TOO SHORT
- `Produs de calitate pentru grădină. Comandă acum.` TOO VAGUE + TOO SHORT
- `Garden gnome decorativ pentru grădină.` ENGLISH WORD — FORBIDDEN

**Romanian language — common mistakes to avoid:**
- SAY "pierdere de păr" or "păr mort" — NOT "manage pierderile" (never leave English verbs)
- SAY "elimină" — NOT "removes"
- SAY "îndepărtează eficient" — NOT "indeparteaza efficient"
- SAY "ușor de utilizat" — NOT "easy to use"
- SAY "pentru câini și pisici" — NOT "pentru pets"
- Always use diacritics: ă â î ș ț — never write "a" when it should be "ă"

## Rules — URL Slug

| Rule | Detail |
|------|--------|
| Format | Lowercase, hyphens only — no underscores, no special characters |
| Length | Max 50 characters |
| Diacritics | Always strip: ă→a, â→a, î→i, ș→s, ț→t |
| Keywords | Primary keyword first, most important words only |
| Stop words | Remove: de, din, pentru, si, cu, a, al, la, in, pe, cel, cu |
| No brand | Never include brand name in slug |

**Examples:**
- `gnom-beat-decorativ-gradina-18cm` OK
- `pieptene-animale-doua-fete-otel` OK
- `cutie-baloane-aniversare-30x30` OK

---

## Rules — Image Alt Text

| Rule | Detail |
|------|--------|
| Length | 5-10 words per image |
| Language | Romanian with diacritics |
| No prefix | Never start with "imagine" or "fotografie" |
| Varied | Each image should have unique alt text |
| Descriptive | Describe what is shown, include product name and key attribute |

**Examples:**
- `Gnom beat decorativ pentru grădină, figurină roșie 18 cm` OK
- `Pieptene cu două fețe pentru câini, oțel inoxidabil albastru` OK

---

## Quality checklist

- [ ] Product title: 40-70 chars, no brand, ends at COMPLETE word, no bare numbers
- [ ] Meta title: 55-65 chars TOTAL with brand, no dashes in keyword part, keyword first
- [ ] Meta description: 150-165 chars, 100% Romanian, 2+ concrete specs, ends with CTA
- [ ] Slug: lowercase, no diacritics, max 50 chars, keyword first, no brand
- [ ] Alt texts: 5-10 words each, Romanian with diacritics, unique per image
- [ ] Zero English words in Romanian output
